## If you do rewrite one

Match what the 14 survivors do, since that is the standard the whole site now holds to:
5–8 H2 headings, 1,100+ words, a meta description of 150–160 characters, a
"Common questions" block with 3+ Q&A pairs (the theme turns that into FAQPage schema
automatically), and internal links to the relevant state or city page.

Reusing the original URL is fine and preferable — remove that line from the redirect
file when you publish, or the redirect will shadow the new post.
